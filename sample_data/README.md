# Offline sample

`terrafly_synthetic_aerial.png` is a small, deliberately asymmetric synthetic scene generated by `scripts/create_offline_sample.py` for offline judge demonstrations and orientation checks.

It is original TerraFly project material released under CC0-1.0. It is not satellite data, ground truth, or evidence of model accuracy.

## Final calibration demonstration pair

- `terrafly_calibration_demo_input.tif` wraps the same CC0 scene in an EPSG:32643 test grid.
- `terrafly_calibration_demo_reference.tif` is a **synthetic software oracle** derived from the verified model output with a known scale of 40 and offset of 100. It contains twelve training-only outliers so robust fitting is exercised.
- `terrafly_calibration_demo_metadata.json` records hashes, model revision, device, equation, and the non-ground-truth warning.

Use these two GeoTIFFs only to demonstrate that TerraFly's calibration, rejection gate, metadata, and metric-artifact plumbing work. The reference is not surveyed, not independent, and not evidence of model accuracy.
